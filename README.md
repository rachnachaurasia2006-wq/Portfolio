Welcome to my Personal Portfolio Website! 👩‍💻

## 🚀 Features

- **Home Section:** Introduction and profile picture.
- **About Section:** Personal introduction.
- **Skills Section:** Displays my technical skills.
- **Education Section:** Academic background.
- **Projects Section:** Showcases my completed projects.
- **Contact Section:** Contact details and social media links.
- **Responsive Design:** Compatible with mobile, tablet, and desktop screens.
- **Dark/Light Mode:** Switch between dark and light themes.
- **Mobile Navigation:** Responsive navigation menu.
- **Smooth Scrolling:** Smooth navigation between sections.
- **Scroll Animations:** Attractive visual effects while scrolling.
- **Resume Download:** Downloadable resume.
